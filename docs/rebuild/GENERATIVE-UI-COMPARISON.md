## Transferred patterns, implementation and choices

- **Applied:** closed renderer catalog in `web/experience.mjs`, still behind
  `validateLayout`; props/facts come from admitted records. No arbitrary model
  HTML/JS or extra inference solely to render. Existing layout inference can
  reorder only the admitted contract; this is not full semantic generative UI.
- **Applied:** stable map-loading shell; independently fetch exact question,
  geometry/manifest/pin and expiring legal status. The original question becomes
  available before slow geometry. Geometry still waits for question/label
  admission; legal status is rechecked at display time. No schema/source guard
  was removed for faster rendering.
- **Applied following native interaction review:** occurrence source details
  disclose exact dates/version hash on demand in `web/inventory-view.mjs`.
  Original source link and material snapshot/currentness warning remain visible.
  Details opening halts speech through the existing owner. No third-party code
  or license-dependent component was imported.
- **Retained:** local expanded/selected state separate from verified facts;
  existing turn/revision, request ID, source/language and audio leases reject
  stale results. Source views preserve every printed candidate row with equal
  missing-background fields, not inferred positions or rankings.
- **Not adopted:** embedding arbitrary generated HTML/PDF frames, relying on
  a model's assertion that a widget works, substituting document selectors for
  actual maps, or promoting unreviewed translations. Current official geometry
  and matching view boxes remain in the local map comparison.

[Native visualizations](https://learn.chatgpt.com/docs/visualizations) documents
an interaction capability. [ChatGPT UI components](https://developers.openai.com/plugins/build/chatgpt-ui)
are a separate integration surface. Neither observation establishes an embeddable
native private renderer for this web application.

## Open-source alternatives considered, not installed/benchmarked

Parent's official-reference research supplied these alternatives. No source was
copied, no dependency installed and no upstream version/commit is invented.

| Alternative | Useful pattern | Decision now |
| --- | --- | --- |
| [assistant-ui](https://www.assistant-ui.com/docs/guides/voice) | React conversation state and duplex voice adapters; MIT per researched repository | Consider only if measured benefit justifies adopting React; current code is Python/plain JS. |
| [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/stream-protocol) | Typed streaming protocol, including Python SSE; Apache2 per researched SDK | Protocol inspiration; do not add experimental RSC/streamUI or a second session owner. |
| CopilotKit / AG-UI | Tool-rendering, snapshot/revision/patch concepts; MIT per parent research | Consider versioned events, not an additional orchestration runtime. |
| [ChatKit](https://developers.openai.com/api/docs/guides/chatkit) | Embeddable conversation/structured widgets with custom Python server | Separate from native ChatGPT; SDK licensing does not prove a fully offline/self-hosted frontend. No migration now. |
| Hosted Tambo | Generative component selection | Rejected for this milestone: parent research identified announced hosted shutdown. No hosted dependency added. |

Licenses/versions must be reverified before any actual code import. The comparison
supports retaining the small current catalog, not a claim that it outperforms
these unbenchmarked libraries. More recorded-event coverage remains: long/RTL
content, reconnect/duplicate events, disputed claims, unknown jurisdiction,
actual screen-reader/mobile-device use and synchronized fresh spoken responses.
