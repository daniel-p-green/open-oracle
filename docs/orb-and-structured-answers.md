# Orb and structured answer views

Added October 10, 2026. Nothing here calls ElevenLabs, OpenAI or AWS, and no API key is needed: the Orb is a client-side component, not a hosted voice service.

## The Orb

`#orb` in `web/index.html` is now the [ElevenLabs UI Orb](https://ui.elevenlabs.io/docs/components/orb) (MIT), copied from `github.com/elevenlabs/ui` into `web/orb-src/components/ui/orb.tsx`. The registry site blocked scripted downloads, so the file came from the public repository at the commit named in its header. One local change: the noise texture is served from `/orb-noise.png` (generated by `web/orb-src/make_noise.py`) because the page's Content-Security-Policy allows no third-party hosts.

`web/orb-src/main.tsx` mounts it as a small React island and is bundled to `web/orb.js`. The vanilla app still owns state. `app.js` writes `#orb[data-state]` and the island maps it:

| `data-state` | Orb | Driven by |
| --- | --- | --- |
| `ready` | idle, gold | nothing |
| `listening` | green, reacts to voice | microphone level |
| `thinking` | amber, slow drift | built-in animation |
| `speaking` | deep green, reacts to output | output level, see below |
| `uncertain` | muted, dashed ring | nothing |

Audio levels come from Web Audio analysers that are never connected to a speaker. The island plays, records and uploads nothing.

- **Let the orb hear you** asks for the microphone and feeds only its loudness to the orb. It does not transcribe, so questions are still typed. It is hidden on insecure origins and in the compact 800×480 layout.
- During the GPT-Live preview the orb follows that session's microphone stream automatically.
- **Speaking has no real audio source yet**, because generated speech is still held. When a validated playback path exists, call `window.OpenOracleOrb.attachOutput(stream)` with the stream being played and set `data-state="speaking"`.
- `/?orb-demo=1` cycles all four states with simulated levels and says so on screen. Use it to show the motion without a microphone or model.

Without WebGL 2, or with reduced motion requested, the island does not mount and the original static CSS indicator stays. The orb shows application state. It is not a sign that an answer was checked.

Rebuild after editing anything in `web/orb-src/`:

```sh
cd web/orb-src && npm install && npm run build
```

## Structured answer views

`web/intelligent.js` adds views on top of the answer `app.js` just rendered. It reads the same `/api/ask` result (`latest`) and never fetches or generates anything, so voice, text and these views share one evidence boundary.

- **Response type label** above the answer text: source wording found, one more detail needed, coverage gap, outside what this guide does, sent to the official source, source changed, no answer released.
- **Linked passages** for the COMBAT explanation card: each quoted span is highlighted inside the original wording, and each explanation part has a "Find this in the original wording" control. Offsets are re-checked against the source text before anything is highlighted.
- **Source coverage, side by side** when a response carries sources for two or more people: one column per person, one row per source. A missing source is written out as a coverage gap. The table compares what sources exist, never positions.
- Codex's `candidate_comparison` card (same-question answers) is left as rendered. The coverage table only appears for the source-gap response, so the two never show together.
- **Next, if useful** buttons that submit an ordinary follow-up question through the same form.

## Checked and not checked

Checked in a browser against a local server on port 8766: the orb renders in all states with no CSP or console errors, the level meter responds to a synthetic test tone, the passage links, coverage table, follow-ups and reset behave, and the 800×480 layout still keeps the submit button in view. The existing Python and Node suites pass.

Not checked: a real microphone, the GPT-Live stream, any real output audio, and WebGL performance on the Raspberry Pi.

The server running on port 8765 must be restarted to serve the new files. Until then that page loads without the orb island and falls back to the static indicator.
