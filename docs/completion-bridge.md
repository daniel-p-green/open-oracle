# Same-agent private evidence-completion bridge

`ResearchRequest(..., completion_setup=CompletionSetup(...))` now executes the bounded completion tools in its existing Strands Agent and finishes through existing `CitedAnswer`. The default constructor exposes no completion tools. Trusted fact/source definitions are host-owned; no model tool or HTTP input creates them. The guard retains one-expansion/eight-read caps, shared request timeout/cancellation, sequential dispatch, model/tool/token budgets, no retries and safe receipts.

Every successful mapped read independently rechecks exact registry citation, purpose, scope, searched fact membership and original/extraction hashes before registering the issued span in `read_by_part` and `citation_spans`. A provisional ballot read for an expiry/date fact does not authorize a legal-reference citation. Core finalization rechecks every finding against the fact's approved witness and keeps explicit missing-context gaps. Conflicts, cross-fact IDs and unsupported fact types hold; they are not converted into predictions.

Actual repository offline tests demonstrate eight authored model dispatches, thirteen tool dispatches, one missing-fact-triggered context expansion and three exact per-fact source bindings. Missing context preserves one primary finding and two explicit `missing_legal_reference` gaps. These are SDK/tool executions with synthetic model events, not provider inference or semantic approval. The private draft is never publicly displayed or spoken. Standalone policy completion counters and core request completion are separate; the core receipt is finalized when the request closes.

The source-only HTTP route remains unchanged. The native buffered AG-UI adapter explicitly rejects this new completion mode until its cloning/tool seams are integrated. Public activation still requires independent finite legal-context release and display mappings that preserve the ordinance attribution, voter condition and proposed/current-law distinction, then the unchanged Decisions checks and post-review rebind. Citation correctness is not entailment. No extra provider trial is implied.

Validation: 8 bridge tests, 20 module tests, 6 schema tests, 11 release tests, 16 research tests (2 optional native skips), 8 quality-receipt tests and 11 research/browser tests. No capture, playback, embedding or provider call in these checks.
