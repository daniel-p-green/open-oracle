and actual player callbacks still need production adapters. GPT-Live deltas/delegation

language transcript fence; signed/decimal/unit/control differences are held. The
synthetic fixtures and tests are not provider review or physical audio evidence.

`.venv/bin/python -B -m unittest discover -s experimental/continuous_voice -p 'test_*.py'`
and `node --test experimental/continuous_voice/test_client.cjs experimental/continuous_voice/test_cedar.cjs`.
